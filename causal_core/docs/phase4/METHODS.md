Generated by `python -m scripts.phase4_stats_report` from `causal_core/analytics/catalog.py`. Do not edit by hand.

The registry runs the generic prechecks (question kind, input shape, metadata, estimand family, source regime, forecast work vs cap) before any method code. Each method then runs its own checks and returns a typed refusal from the list below when a premise fails. `refused()` raises if a method tries an undeclared code.
