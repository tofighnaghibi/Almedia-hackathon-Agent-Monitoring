# Stress cases

Made by `python scripts/stress_cases.py`: 11 targeted cases, 10 pass their stated expectation. Each case is a seeded 30-day simulated history with routine decoy releases and one event (or the pair the case is about), replayed by `python -m brain.run --replay` over the hours around the event and judged only from the files the brain wrote, with the sim.score rules. A failed case is what the system does today. The data is simulated.
